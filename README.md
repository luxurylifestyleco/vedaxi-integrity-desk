# Research-integrity desk

Not Elastic Web. Elastic Web is [vedaxi-elastic](https://github.com/luxurylifestyleco/vedaxi-elastic).

A paper desk and a video desk show evidence. An agent may point at a discrepancy. Only a person can confirm or reject it. The research content is fixture data.

```mermaid
flowchart LR
  paper[Paper] --> propose[Agent proposes]
  video[Video] --> propose
  propose --> human[A person confirms or rejects]
```

[Open the desk](https://vedaxi-integrity-desk.vercel.app)
